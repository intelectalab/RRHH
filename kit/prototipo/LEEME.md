# Prototipo GestiaHR

**Abrir `GestiaHR_prototipo.html`**: es el prototipo completo en un solo archivo (todos los módulos).

La carpeta `fuentes/` es solo para desarrollo: `core.html` es el núcleo SIN módulos (si se abre solo, muestra únicamente Inicio, Personas, Organización y Seguridad) y cada `mod-N-*.js` es un módulo. `python3 build.py` dentro de `fuentes/` vuelve a generar el archivo único (`index.html`).
